# Rencana Tahap 1

Pelaksanaan langsung di chat ini sesuai instruksi pengguna. Setiap modul memakai data demo bertipe, komponen bersama, dan penyimpanan browser yang terpisah dari sumber asli.

- [ ] Fondasi: package, font lokal, tokens, layout publik/admin, tema, mock store dan aturan domain.
- [ ] Halaman publik: beranda, profil/divisi, berita/announcement, album/lightbox, kontak, privasi.
- [ ] Flow: peminjaman, status dan invoice PDF, OR/revisi dan salinan PDF, konfirmasi donasi, PDF reader.
- [ ] Admin: daftar/filter/pagination, editor, role UI, feature state, periode OR, persetujuan pinjaman, arsip dan audit, ekspor.
- [ ] Verifikasi: domain test, typecheck, lint, build, browser QA desktop/mobile, dokumentasi dan preview lokal.
